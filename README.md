# IrisStudio

Studio de création musicale façon FL Studio, **gratuit et fait pour apprendre** : séquenceur pas à pas, piano roll, playlist, mixeur avec effets, kicks hardcore/uptempo, percussions, synthés, sampler, export WAV, projets de démo et **cours interactifs**.

Moteur audio en Rust (cpal), interface HTML/JS dans [Tauri 2](https://tauri.app). Windows. Compiler : `cargo build --release`.
